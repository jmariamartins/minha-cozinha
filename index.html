ℹ️ Sobre esta app

A Minha Cozinha é uma ferramenta pessoal de planeamento culinário. As tuas receitas e preferências ficam guardadas localmente no teu browser e nunca são partilhadas.

📘

Como usar a Minha Cozinha

Tudo o que precisas de saber para tirar o máximo partido da app

1

Importar receitas

As receitas são carregadas automaticamente a partir da pasta recipes/ do repositório GitHub. Toca em ☁️ Sincronizar Receitas na página inicial para actualizar — a app faz isso sozinha ao arrancar se já tiver passado uma hora desde a última sync. Para adicionar uma receita pontual sem passar pelo GitHub, usa Importar ficheiro local, que acrescenta sem apagar o que já existe.

💡 Cada receita é um ficheiro .txt separado. Usa o VS Code para os criar e editar — evita caracteres RTF do TextEdit do Mac.
obrigatório# Título da receita
obrigatóriocategoria: Carne · Peixe · Vegetariano · Sopa · Massa · Arroz · Salada · Lanche · Sobremesa
obrigatórioporções: 4
obrigatóriotempo: 35 (em minutos)
obrigatóriodificuldade: Fácil · Médio · Difícil
obrigatóriomodos: Normal · Bimby · Airfryer (separados por vírgula)
opcionalprep: marinada 30 min antes — aviso de preparação antecipada
opcionaltipo: frito — marca receitas fritas/panadas (limitadas a 1 por plano)
opcional## Nutrição com calorias, proteína, hidratos, gordura por dose
⏱ Para adicionar um temporizador a um passo, coloca ⏱ 8 (número de minutos) na linha imediatamente a seguir ao passo.
2

Todas as Receitas

Navega e filtra o teu livro de receitas. Os filtros estão organizados em três linhas:

  • Categoria — Carne, Peixe, Vegetariano, Sopa, Massa, Arroz
  • Perfil — Alta Proteína (≥25g/dose), Low Carb (≤20g), Low Fat (≤10g), Favoritos, Rápida/Média/Demorada
  • Modo — Normal, Bimby, Airfryer

Toca em qualquer receita para a abrir. No topo encontras o botão 🤍 para a marcar como favorita.

3

Ver uma receita

Dentro de cada receita podes:

  • Ajustar as doses — as quantidades dos ingredientes actualizam automaticamente
  • Tocar em cada ingrediente para o riscar da lista à medida que cozinhas
  • Mudar de modo de preparação (Normal / Bimby / Airfryer) pelos separadores
  • Iniciar os temporizadores de cada passo — tocas e começa a contagem decrescente; toca de novo para cancelar
  • Usar o botão 🔊 para ouvir os passos em voz alta sequencialmente em Português
⚠️ Se a receita tiver um aviso de preparação antecipada (ex: marinada), aparece um banner laranja logo no topo.
4

O que tenho no frigorífico?

Adiciona ingredientes que tens em casa um a um. A app lista todas as receitas que os incluem, ordenadas por número de ingredientes correspondentes.

  • 2/2 ingredientes (verde) — tens todos os ingredientes necessários
  • 1/2 ingredientes (laranja) — tens alguns mas faltam outros
5

Planeamento Semanal

Define quantos dias, pessoas e refeições por dia. Depois escolhe as tuas preferências:

  • Excluir categorias — remove categorias que não queres ver no plano
  • Modo de cozinha — filtra por método (opcional)
  • Dificuldade e Duração — limita a complexidade e tempo de confecção
  • Variedade — máx. 2 receitas da mesma categoria, máx. 2 da mesma proteína, máx. 1 frita
  • Poupança — escolhe receitas que partilham ingredientes para minimizar compras
🧠 O modo Sugerido (IA) usa o Claude para escolher as receitas de forma mais inteligente. Requer uma chave API Anthropic — configura em ⚙️ Definições.

O resultado mostra-te as receitas seleccionadas, a lista de compras agrupada por secção do supermercado (Frescos → Talho → Peixaria → Congelados → Laticínios → Mercearia → Bebidas → Temperos) e o calendário semanal.

6

Calendário semanal

Alterna entre 📋 Lista e 📅 Calendário para ver o plano. No calendário:

  • Cada refeição é um evento independente — uma receita de 4 doses para 2 pessoas ocupa 2 slots em dias à tua escolha
  • (sobras) indica que é a segunda (ou mais) vez que essa receita aparece
  • Toca numa refeição para a seleccionar (fica verde), depois toca noutra para as trocar de dia
  • O botão ↔ substitui a receita daquele slot por outra do teu livro — as outras doses da mesma receita não são afectadas
7

Substituições

Uma lista de alternativas para os ingredientes mais comuns. Filtra por Vegano, Mais saudável, Mais barato, Sem glúten ou Sem lactose. Cada substituição indica a proporção e uma nota prática.

8

Definições

Acede pelo ícone ⚙️ no canto superior direito. Cola aqui a tua chave API Anthropic para activar o modo Sugerido no planeamento. A chave fica guardada localmente no teu browser e nunca é partilhada.

🔑 Obtém a tua chave em console.anthropic.com → API Keys → Create Key. O custo por plano gerado é inferior a 0,01€.
